# Кулинарная книга (Recipe Book)

Десктопное приложение на Python (Tkinter) для управления рецептами. Всё сохраняется локально в папке «Документы».

## ✨ Возможности

- **📖 Управление рецептами:** Группы, названия, время, сложность, порции, теги, избранное.
- **🖼️ Фотографии блюд:** Добавление и удаление фото к каждому рецепту.
- **🔍 Поиск и фильтры:** Поиск по названию, фильтр по времени, сложности и тегам.
- **📅 Планировщик меню:** Распределение рецептов на неделю (завтрак, обед, ужин).
- **🛒 Список покупок:** Автоматическое создание списка продуктов на основе плана питания.
- **🍳 Режим готовки:** Пошаговый режим с таймером для каждого шага.
- **📊 Статистика:** Популярные теги, частые ингредиенты, среднее время готовки.
- **📥 Экспорт:** Сохранение рецептов в JSON, TXT, PDF, HTML, CSV и Markdown.
- **↩️ История действий:** Отмена и повтор действий (Ctrl+Z / Ctrl+Y).

## 🖥️ Системные требования

- **ОС:** Windows / Linux / macOS
- **Python:** 3.8 или выше

## 🚀 Установка и запуск

1. Скачайте этот репозиторий.
2. Установите зависимости:
   pip install -r requirements.txt
3. Запустите программу:
   python main.py

## 📖 Как пользоваться

1. Нажмите «➕ Новая группа», чтобы создать категорию (например, «Супы» или «Десерты»).
2. Выберите группу и нажмите «📝 Добавить рецепт». Заполните ингредиенты, шаги, время и теги.
3. Используйте вкладку «📅 Планировщик меню», чтобы распределить блюда на неделю.
4. Нажмите «🛒 Создать список покупок» — программа сама соберёт все ингредиенты из плана.
5. Для удобной готовки выберите рецепт и нажмите «🍳 Режим готовки».
